# 리쥬네브 인스타 릴스 예약 작업 (메타 비즈니스 스위트)

이 문서는 다른 Claude 세션이 준비한 예약 목록이다. 대표님 컴퓨터의 Claude 앱 브라우저로
메타 비즈니스 스위트(https://business.facebook.com)에 접속해, 아래 11개 릴스를 인스타그램 @junevk_kyj_ 계정에 예약한다.

## 작업 방법
1. 영상은 아래 URL에서 받아 바탕화면(연결된 폴더)에 저장한 뒤 업로드한다.
2. 비즈니스 스위트 → 만들기 → 릴스 → 게시 위치는 **인스타그램만** 선택(페이스북 체크 해제).
3. 영상 업로드 → 캡션 칸에 아래 캡션을 줄바꿈 그대로 붙여넣기.
4. 예약 → 날짜·시간(한국 시간) 입력 → 예약 확정.
5. 첫 댓글은 예약 기능에 없으면 생략(게시 후 대표님이 직접 달기).
6. 한 편 끝날 때마다 예약 목록에 들어갔는지 확인하고, 마지막에 표로 보고한다.
7. 로그인·2단계 인증이 나오면 대표님께 직접 해달라고 요청한다. 계정 설정은 바꾸지 않는다.
8. 대화는 한국어로만 한다.

공통 첫 댓글: `도매·입점 문의는 DM 주세요 🙂`

영상 기본 주소: https://raw.githubusercontent.com/gogi492-star/lejunev-reels/main/reels/
